# What's New? This very tab

RuTerm now has a **What's New** button on the homepage. Clicking it opens this tab,
pulled from the `News/` folder in the source repository — which means notes pushed
to GitHub show up here automatically, stamped by date, newest first.

- Entries are plain `.md` files — write one, push, done.
- A small badge on the button counts how many notes you haven't read yet.
  Opening this tab clears it; it starts counting again as new entries land.
- Everything is also bundled into the app, so the tab works fully offline.
  When a newer entry is fetched from GitHub, the bundled copy is used only as a
  fallback.
